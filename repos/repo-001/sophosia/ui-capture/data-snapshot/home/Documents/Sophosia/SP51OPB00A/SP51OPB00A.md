# Attention Is All You Need
Author: Ashish Vaswani, Noam Shazeer, Niki Parmar, Jakob Uszkoreit, Llion Jones, Aidan N. Gomez, Łukasz Kaiser, Illia Polosukhin
Abstract: Proposes the Transformer, a sequence transduction architecture built entirely on stacked self-attention and point-wise feed-forward layers, dispensing with recurrence and convolution. It reaches state-of-the-art BLEU on WMT 2014 English-German and English-French while training substantially faster than recurrent baselines.
