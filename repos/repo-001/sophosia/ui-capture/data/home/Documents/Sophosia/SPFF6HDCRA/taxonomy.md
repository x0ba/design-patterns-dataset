# Efficient transformer taxonomy (Tay et al.)

- **fixed patterns**: blockwise, strided, local window -> [Longformer](SPPROS545E) (partly)
- **combination of patterns**: [BigBird](SPC0GC5KYS), Axial
- **learnable patterns**: Reformer (LSH), Routing Transformer
- **memory / global tokens**: Set Transformer, ETC, Longformer global attn
- **low rank**: Linformer
- **kernels**: Performer, Linear Transformer
- **recurrence**: Transformer-XL, Compressive

Missing (post-survey): SSMs ([S4](SPI0O8P7X7), [Mamba](SPL7V44MTW)), IO-aware exact attention ([FlashAttention](SPNOBIMUVN)).
