# Dispatch & Booking Software — Requirements

Version 0.4 · Draft for internal review

## Must have

- Real-time vehicle tracking with ≤ 15 s update interval
- Rider booking via app, web, and **phone agent** interface
- ADA-compliant rider app (WCAG 2.2 AA)
- GTFS and GTFS-Flex export
- Role-based access for dispatchers, drivers, and admins

## Should have

- Automated SMS/voice notifications to riders
- Integration with county paratransit (TripSpark) via API
- Reporting: trips by zone, on-time %, no-shows, denials

## Nice to have

- Spanish and Vietnamese rider interfaces
- Open data API for researchers

## Evaluation criteria

| Criterion                                 | Weight |
| ----------------------------------------- | ------ |
| Functionality against requirements        | 35%    |
| Total 3-year cost                         | 25%    |
| Accessibility                             | 15%    |
| Vendor references (similar-size agencies) | 15%    |
| Implementation timeline                   | 10%    |
