# :Isotopes

Lists the known isotopes of one element.

## Synopsis

```vim
:Isotopes {symbol}
```

## Example

```vim
:Isotopes Cl
```

```text
Cl-35   34.969 u   75.78 %
Cl-37   36.966 u   24.22 %
```
